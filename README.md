# The Title Bug 🐞

**404: Job Title Not Found.** A playful career debugger for people who don’t fit into a single job title.

Built by Lital Entin using React, TypeScript and Vite.

## Features

- Interactive career diagnostics (animated terminal)
- Real-world and funny job title generator
- Personal career story
- Visitor career debugger and copyable results
- Automated tests and GitHub Actions CI

## Run locally

```bash
npm ci
npm run dev
```

## Validate

```bash
npm test
npm run build
```
